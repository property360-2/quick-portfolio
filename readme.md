## Overview

This portfolio is built using **Astro 6** and **Tailwind CSS 4**, focusing on extreme performance, clean aesthetics, and a premium user experience. It features a modern design system, smooth animations, and a responsive architecture.

## Tech Stack

- **Core Framework**: [Astro 6](https://astro.build/) - The web framework for content-driven websites.
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/) - Utility-first CSS framework with modern features.
- **Backend Services**: [Firebase](https://firebase.google.com/) - Used for authentication and real-time data operations.
- **Animations**: [GSAP](https://greensock.com/gsap/) - For high-performance, complex web animations.
- **Icons**: [IconSax](https://iconsax.io/) & Custom SVG.
- **Deployment**: Optimized for static hosting (GitHub Pages / Vercel).

## Key Features

- **Blazing Fast Performance**: Utilizing Astro's zero-JS-by-default architecture.
- **Responsive Design**: Seamless experience across mobile, tablet, and desktop.
- **Interactive 3D Elements**: Integration of interactive scenes for enhanced engagement.
- **Case Studies**: Detailed breakdowns of my professional projects.
- **Dynamic Content**: Articles and writings managed through Astro's content-driven patterns.
- **Modern UI/UX**: Glassmorphism effects, smooth transitions, and a curated color palette.

## Project Structure

## Getting Started

All commands are run from the root of the project:

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
The site will be available at `http://localhost:4321`.

### 3. Build for Production
```bash
npm run build
```
The production bundle will be generated in the `./dist/` directory.

### 4. Preview Build Locally
```bash
npm run preview
```
